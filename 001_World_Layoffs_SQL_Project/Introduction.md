# Raw CSV Dataset

The `layoffs.csv` file contains information about company layoffs recorded across different companies, industries, countries, and periods.

The dataset includes details such as:

* Company name
* Location
* Industry
* Total employees laid off
* Percentage of employees laid off
* Layoff date
* Company stage
* Country
* Funds raised by the company

This CSV represents the **raw, uncleaned dataset** used as the starting point for the SQL data-cleaning and Exploratory Data Analysis (EDA) stages of the project.
